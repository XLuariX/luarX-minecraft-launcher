**LuariX Minecraft Launcher** — ретро-лаунчер для Minecraft, созданный для **любого железа**. Лёгкий, мощный, с анализом комплектующих и авто-подбором оптимальной версии. Играйте без лицензии, с модами и ресурспаками.

---

## ✨ Возможности

- 💻 **Работает на любом ПК** – от старых машин до современных сборок.
- 📊 **Автоопределение железа** – CPU, GPU, ОЗУ, тип диска (через WMI/PowerShell).
- 🎯 **Умный подбор версии** – лаунчер сам рекомендует лучшую версию Minecraft под ваше железо.
- 📦 **Установка любых версий** – от 1.0 до последних релизов (список с Mojang).
- 🧩 **Моды, ресурспаки, шейдеры** – добавление файлов `.jar`/`.zip` одной кнопкой.
- 🔧 **Forge / Fabric** – встроенная установка загрузчиков.
- 🌐 **Aternos** – быстрый переход на сайт бесплатного хостинга.
- 💾 **Резервное копирование** – сохранения, скриншоты, `options.txt`.
- 🎨 **Ретро-тема** – чёрно-зелёный стиль (доступна и светлая тема).
- 👤 **Офлайн-режим** – играйте с любым ником без лицензии.
- 🧹 **Портативность данных** – все настройки и файлы игры в `%APPDATA%\LuariXLauncher`.

---

## 💻 Системные требования

- **ОС**: Windows 7 / 8 / 10 / 11 (64‑bit)
- **Java**: JRE 8 или 17 (обязательно) – [скачать](https://adoptium.net/)
- **Место**: ~200 МБ для лаунчера + 1‑2 ГБ на каждую версию Minecraft
- **ОЗУ**: 2 ГБ (минимум), 4 ГБ+ (рекомендуется)

---

## 📥 Установка

1. Скачайте `LuariXLauncher_Setup.exe`.
2. Запустите установщик → следуйте инструкциям.
3. Если Java отсутствует, установщик предложит открыть страницу загрузки.
4. Ярлык появится на рабочем столе и в меню «Пуск».

**После запуска лаунчера:**
- Вкладка **📦 Версии** → выберите версию → **Установить**.
- Вкладка **⚙ Комплектующие** → **Автоопределение** → **✨ Подобрать версию**.
- Вкладка **▶ Играть** → выберите ник, ОЗУ → **ЗАПУСТИТЬ**.
